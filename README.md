常规订阅地址：https://raw.githubusercontent.com/Bitithao/tv-subscriptions/main/selene.txt

## 当前维护方式

受限自动维护已通过首轮验收：2026-11-08 发布 65 个主频道、53 个备用频道，18 项离线测试通过。此数量是当次检测结果，以 health.json 为准。按用户要求改为每两天检测一次，计划在北京时间 11:23 执行（以 2026-11-08 为基准，下一次为 11-10）。GitHub 调度可能延后；中间一天仅判断日期，不请求直播源。手动运行或修改检测代码时仍可立即检测。不依赖家里的电脑。

- 只检测 allowed-origins.json 中为每个频道选定的服务器。该文件表示访问范围，不是安全认证。
- 抓取 CCSH、vbskycn 清单后，仅接纳同一频道、同一已选服务器上的直接 M3U8 地址。新的入口服务器不会自动加入清单。
- 仅从已选入口出发，实时检查 M3U8 跳转的公网地址、媒体路径及响应类型，保留签名参数，最多三次跳转；跳转页面正文直接关闭，不读取或执行脚本。拒绝 HTTPS 降级、HTML/JavaScript 响应、私网地址和停止更新的列表。视频分片必须留在选定或实际解析到的播放列表服务器。
- jiduo.me、jdshipin.com 及其子域名继续隔离。普通媒体 CDN 跳转须通过上述限制，不能仅凭 HTTP 200 就放行。
- 每条候选实际读取视频分片，等待直播列表前进后再检查下一片。每频道最多一条主线、一条备用线。
- 翡翠台优先使用已在电视试播并测得 1920×1080、25 fps 的直连候选；清晰度和可用性可能随上游改变。
- 检测失败线路在成功发布时剔除。若整轮异常或翡翠台全部失败，保留上次完整列表并写入失败报告，避免云端网络差异清空电视清单。

公开来源可能失效。HTTP、媒体格式和连续性检查不能保证来源安全，也不能保证云端可播的地址在家庭网络同样可播。

## 点播与隐私

当前共 **9 个点播源**：iKun、非凡、最大、优质、量子、360、魔都、虎牙直链、淘片。配置由 [curated-vod.json](curated-vod.json) 管理；三个原有源优先，其余用于片库与线路补充。

本轮参考 TVBox 配置提取兼容的 type=1 JSON 接口，增加虎牙直链和淘片。饭太硬的 type=3 CSP/JAR 不能直接导入 Selene，也没有运行这些插件。

电脑测试覆盖32个候选、16类片目，并加测豆瓣Top250前25部、8个当季新番主题及译名；共1086次目录请求和59次媒体抽检。不是完整测试250部电影，也不是电视整集播放保证。详见 [覆盖、分辨率和失败记录](vod-coverage-report.txt)；[上一轮质量测试](vod-test-report.txt)保留作历史记录。

**搜索提示：**

- “用循环利息回收魔力”请搜 **借出去的魔力**。非凡、最大、量子、优质、360、魔都、虎牙的第6集已测得1920×1080；iKun当次为第5集。
- “转生就是剑”也可搜 **转生成为魔剑**。
- “哈利·波特与魔法石”没有结果时，试 **魔法石** 或 **哈利波特**。
- 海贼王：八个源测到1178集，淘片当次只测到1176集，不能作为最新集的替代。

新源并非所有影片都更清晰，部分老片仍有低清版本或广告。优先保留原有较好线路；淘片仅作老片补充（本轮一部电影媒体失败，其他样本可播）。

每两天云端任务检查目录并更新直播；点播临时失败会报告并保留配置，不会自动删到只剩一个源，也不会全量导入未测来源。目录检查不是逐集播放检查。电脑无需保持开机。

订阅地址不变：电视方便时点「设置 → 立即刷新订阅」，重新搜索片名并选择源。旧观看记录可能仍绑定旧源，本次没有清空或操作电视。远程清单数量不代表电视当前页面一定显示同样数量。

本仓库不含用户账号、VPN订阅、节点凭据或观看记录。
