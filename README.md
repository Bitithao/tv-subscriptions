## 当前维护方式

受限自动维护已通过首轮验收：2026-11-08 发布 65 个主频道、53 个备用频道，18 项离线测试通过。此数量是当次检测结果，以 health.json 为准。按用户要求改为每两天检测一次，计划在北京时间 11:23 执行（以 2026-11-08 为基准，下一次为 11-10）。GitHub 调度可能延后；中间一天仅判断日期，不请求直播源。手动运行或修改检测代码时仍可立即检测。不依赖家里的电脑。

- 只检测 allowed-origins.json 中为每个频道选定的服务器。该文件表示访问范围，不是安全认证。
- 抓取 CCSH、vbskycn 清单后，仅接纳同一频道、同一已选服务器上的直接 M3U8 地址。新的入口服务器不会自动加入清单。
- 仅从已选入口出发，实时检查 M3U8 跳转的公网地址、媒体路径及响应类型，保留签名参数，最多三次跳转；跳转页面正文直接关闭，不读取或执行脚本。拒绝 HTTPS 降级、HTML/JavaScript 响应、私网地址和停止更新的列表。视频分片必须留在选定或实际解析到的播放列表服务器。
- jiduo.me、jdshipin.com 及其子域名继续隔离。普通媒体 CDN 跳转须通过上述限制，不能仅凭 HTTP 200 就放行。
- 每条候选实际读取视频分片，等待直播列表前进后再检查下一片。每频道最多一条主线、一条备用线。
- 翡翠台优先使用已在电视试播并测得 1920×1080、25 fps 的直连候选；清晰度和可用性可能随上游改变。
- 检测失败线路在成功发布时剔除。若整轮异常或翡翠台全部失败，保留上次完整列表并写入失败报告，避免云端网络差异清空电视清单。

公开来源可能失效。HTTP、媒体格式和连续性检查不能保证来源安全，也不能保证云端可播的地址在家庭网络同样可播。

## 点播与隐私

2026-11-08 安全与广告复核后仍有 **9 个点播源**，用 **如意替换淘片**。淘片封面返回跳往未核实域名的302，未跟随，先隔离；不将其描述为已确诊病毒。

当前顺序：**如意优先试播**；非凡、最大、优质、量子、iKun保留并标注插播/水印；魔都、虎牙、360作为备用。配置见 [curated-vod.json](curated-vod.json)。

此前只看少量画面未能发现广告，这一轮在切段边界发现iKun、非凡、优质、量子、360、魔都的博彩插播，最大和虎牙等有广告水印。如意两部样本共22张画面未见明显博彩广告，但不承诺全片无广告。

如意样本为1080p；360在本次12段连续下载中有9段慢于播放，已降为缓冲备用。所有结论来自电脑抽样，不是电视长时间播放保证。详见 [片库、分辨率、速度、广告与安全报告](vod-quality-safety-report.txt)。[前一轮覆盖报告](vod-coverage-report.txt)和[早期质量报告](vod-test-report.txt)仅作历史记录，以本轮发现为准。

片库测试参考豆瓣Top250前25部及当季新番。新增如意对同样33个目录关键词均有匹配；有记录不等于全部影片可播。源多不等于内容独立，也不为了数量加入跳转页面或未经验证的脚本源。

**搜索提示：** “用循环利息回收魔力”请搜 **借出去的魔力**；“转生就是剑”也可搜 **转生成为魔剑**；哈利波特可尝试 **魔法石**。饭太硬的CSP/JAR不能直接导入Selene，本轮没有运行这些插件。

每两天云端任务检查目录、每源一张封面的HTTPS和图片文件头，以及现有直播线路。封面跳转不跟随，异常写入 health.json 的 `vod_catalogues.*.poster`；这是有限检查，不是完整杀毒或逐集广告识别。真实客户端仍可能遇到上游变化，网络临时失败会保留配置并记录。

订阅地址不变，电脑无需常开。电视方便时「设置 → 立即刷新订阅」再重新搜索选源。本轮没有操作电视或清空观看记录，直播列表保持不变。视频广告是画面内容，不代表已证实感染，也不要打开其中的网址。

本仓库不含用户账号、VPN订阅、节点凭据或观看记录。
